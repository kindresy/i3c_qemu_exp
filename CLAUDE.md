# Project Rules

## Work Process Documentation

- **Every action must be recorded** in the `docs/` directory with a timestamp.
- **Filename format**: `YYYY-MM-DD-{category}-{brief-description}.md`
- Categories: `setup`, `research`, `analysis`, `coding`, `testing`, `debug`, `ops`, `review`
- Each log entry should include:
  1. Timestamp
  2. Objective
  3. Commands used / code changes
  4. Results or observations
  5. Next steps

Example: `docs/2026-06-09-setup-project-init.md`
